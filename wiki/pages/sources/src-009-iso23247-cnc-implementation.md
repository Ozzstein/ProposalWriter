# Digital Twin Implementation for Machining Center Based on ISO 23247 Standard

**Authors**: Cabral, J.V.A. et al. (2023)
**Type**: paper | **Quality**: medium

## Summary
A case study demonstrating ISO 23247 digital twin implementation on CNC milling equipment using MQTT and MTConnect protocols for real-time data acquisition. The work validates the standard's applicability to legacy manufacturing equipment and shows practical integration pathways using industrial IoT communication protocols.

## Key findings
- MQTT/MTConnect enable real-time data acquisition from CNC equipment
- ISO 23247 framework adapts to legacy manufacturing systems
- Real-time monitoring enables predictive maintenance
- Standard-based approach reduces integration complexity

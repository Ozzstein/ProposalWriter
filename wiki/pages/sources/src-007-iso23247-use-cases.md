# Use Case Scenarios for Digital Twin Implementation Based on ISO 23247

**Authors**: Shao, G. (2021)
**Type**: paper | **Quality**: high

## Summary
The definitive reference for ISO 23247 implementation in manufacturing. Published by NIST, this paper presents three concrete digital twin use cases and provides explicit implementation procedures. It serves as the authoritative guide for translating the ISO standard into operational digital manufacturing systems.

## Key findings
- Three validated use cases demonstrate ISO 23247 applicability
- Concrete implementation procedures provided for DT deployment
- NIST reference implementation framework
- Clear mappings between standard requirements and practical components
